## Notes

- Distribution ID and Domain Name are generated by AWS on creation and will change if a distribution is ever destroyed and recreated. Update this table whenever that happens — don't leave stale values here.
- S3 bucket names and function names are set explicitly in each environment's `main.tf` and stay stable across recreates, since they're chosen by us, not AWS.
- `terraform output` (run inside the relevant `environments/<name>` folder) is the fastest way to pull the current Distribution ID and Domain Name after any apply.
